# Goal-driven training focus v1.4.9
A first goal-specific priority layer, not a new autonomous planner. Confirmed distance selects the training profile; an exact name/date match to a saved ascent value adds an elevation focus. 15 m/km is a configurable product heuristic, not a medical or terrain classification. Unknown terrain remains unknown. The Goals weekly view uses the existing phase and deload logic. Seven-day guidance evaluates deduplicated Garmin/manual cross-training and current protection flags, without modifying the existing day plan. An existing open mobility slot may gain a goal-specific strength focus; a previously recorded rowing/cycling activity may be offered instead of an open easy run in base/build only, with sufficient observed running and no recent hard load. No inferred equipment ownership, automatic workout creation, external API key or extra schedule writes. This is advisory only; rowing/cycling does not yet have a one-click planning workflow. No retrospective 90-day or exercise-specific progression yet.
